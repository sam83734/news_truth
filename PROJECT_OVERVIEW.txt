1. YEH PROJECT KIS LIYE BAN RAHA HAI? (PROBLEM STATEMENT & VISION)
--------------------------------------------------------------------------------
Aaj ke traditional media me teen sabse badi problems hain:
1. Fake News aur Unverified Claims: Social media par koi bhi bina proof ke kuch
   bhi viral kar deta hai jisse confusion aur panic failti hai.
2. Ground Realities ka Missing Hona: Mainstream news channels ground reality
   (aam janta, eyewitnesses, local reporters) se door rehte hain.
3. Censorship & Political Suppression: Jab koi genuine investigative journalist
   bade power wale logon (politicians, powerful corporations) ke khilaf sahi news
   publish karta hai, toh woh server par attack karte hain, database hack karke
   content alter karte hain, ya pressure daalkar news delete karwate hain.

"NextTruth Dispatch - Powered by SusaLabs" ek Next-Generation Investigative & Ground News Platform hai.
Iska aim hai:
- Citizen Reporters aur Staff Journalists ko ek direct ground reporting desk dena.
- Har news piece ke sath proof, geolocation aur verification audit trail attach karna.
- Users ko 100% verified ground reality provide karna jisme koi bias ya fake news na ho.
- SusaLabs DLT (Distributed Ledger Technology) Architecture: Har published news aur
  eyewitness dispatch ka SHA-256 cryptographic hash Merkle root ke sath decentralized
  ledger par immutable seal banata hai. Powerful log site ya database ko alter bhi
  karein, toh bhi tamper alarm trigger hoga aur immutable proof intact rahega!

--------------------------------------------------------------------------------
Maano ek real-life scenario:

District 4 ke Market Square me municipal corporation ne unannounced barricading ki
aur commercial developers ke clandestine contracts ko protect karne ke liye
eyewitness reports suppress karne ki koshish ki.

STEP-BY-STEP WORKFLOW:

Step 1: Ground Eyewitness / Reporter Action (Mobile App ya Web Frontend)
  - Ground par maujood Citizen Reporter (jaise Rohan Sharma) ya Anonymous Whistleblower

  - "SUBMIT NEWS / TIP" button par tap karta hai.

    * Category select karta hai: "Ground Reports" ya "Urgent".
    * Headline: "Market square protests escalate with unauthorized cordons".
    * Incident Location tag karta hai: "Old City Market District - Sector 4".
    * Eyewitness details & evidence notes likhta hai.
    * Real-time camera se photo ya video attach karta hai.
    * Whistleblower mode: Agar reporter ko threat ho, toh "Anonymous Whistleblower Mode"
      on karke bina personal metadata ke zero-knowledge secure report bhej sakta hai.
  - "TRANSMIT TO VERIFICATION DESK" button click karta hai.

Step 2: Backend Ingestion & Cryptographic DLT Ledger Minting
  - Report Backend API (`POST /api/submissions`) par securely store hoti hai.
  - Backend is submission ko ek unique ID, timestamp, reporter role ke sath
    status: "PENDING" me rakhta hai.

Step 3: Verification & Editorial Review (Admin / Chief Editor)
  - Chief Editor (Dr. Alexander Vance) ko alert milta hai.
  - Editor Admin Desk (`PATCH /api/admin/submissions/:id/status`) par check karta

  - Authentic hone par Editor use "APPROVED" karta hai:
    * System automatically use official "VERIFIED GROUND" Article bana deta hai.
    * SusaLabs DLT Service turant use ek naye Block me mine karta hai:
      SHA-256 Content Hash, Merkle Root, IPFS CID snapshot, aur 3 validator signatures:
      1. SusaLabs Core Truth Node (Validator 01)
      2. Independent Press Guild Node (Validator 02)
      3. Citizen Witness Network (Validator 03)

Step 4: Real-time News Delivery on Web & Mobile App
  - Readers Web Portal (Dribbble-designed modern editorial interface) aur Mobile App
    par instant alert pate hain.
  - Hero Card & Weekly Top News update hote hain jisme "VERIFIED GROUND" aur "DLT SEALED"
    ka blue/green badge dikhta hai.
  - Readers chahe to:
    * Pura article padh sakte hain.
    * Built-in Audio Narration player on karke article sun sakte hain (1x, 1.5x, 2x speed).
    * "Ground Verification Audit Dossier" aur "DLT Proof" check kar sakte hain.
    * Live video feed me ground se aayi live coverage stream dekh sakte hain.
    * "Verify Live Hash" click karke check kar sakte hain ki kisi ne database me
      ek bhi word change toh nahi kiya!


3. DLT (DISTRIBUTED LEDGER TECHNOLOGY) ANTI-CENSORSHIP ARCHITECTURE
--------------------------------------------------------------------------------
Bade power wale logon aur hackers ke suppression tactics se bachne ke liye SusaLabs DLT Protocol:

1. Cryptographic Fingerprint (SHA-256):
   Har news dispatch ka formula:
   `ContentHash = SHA256(Title + Excerpt + FullContent + AuthorName + Geolocation)`
   Ek bhi character ya comma badla, toh hash mismatch ho jata hai.

2. Blockchain Chaining:
   Har block previous block hash ke sath linked hai:
   `BlockHash = SHA256(BlockIndex + PreviousHash + ContentHash + MerkleRoot + Timestamp)`
   Peeche ka koi bhi record delete ya overwrite nahi kiya ja sakta.

3. Multi-Node Byzantine Consensus:
   Teen independent validator nodes live signatures dete hain:
   - Node 1: SusaLabs Core Truth Node
   - Node 2: Independent Press Guild Node
   - Node 3: Decentralized Citizen Witness Network

4. Tamper Alarm & Self-Healing:
   Agar koi database ko alter karne ki koshish karega, public verifier turant
   "CRITICAL TAMPER DETECTED: DB hash differs from immutable Genesis Ledger hash"
   flag kar dega, aur IPFS decentralized snapshot se original news restore ho jayegi.

6. DUSRE DEVELOPER KE LIYE SETUP GUIDE (HOW TO RUN LOCALLY)
--------------------------------------------------------------------------------

A. PREREQUISITES:
   - Node.js (v18, v20, ya v24)
   - npm (v9, v10, ya v11)

B. 1. BACKEND RUN KAISE KARE:
   1. Terminal open kare aur backend directory me jaye:
      cd backend
   2. Dependencies install kare:
      npm install
   3. Backend dev server start kare:
      npm run dev
      -> Server URL: http://localhost:5000
      -> Health check URL: http://localhost:5000/api/health
      -> DLT Ledger: http://localhost:5000/api/dlt/ledger

C. 2. WEB FRONTEND RUN KAISE KARE:
   1. Naya terminal open kare aur frontend directory me jaye:
      cd frontend
   2. Dependencies install kare:
      npm install
   3. Web dev server start kare:
      npm run dev
      -> Web Portal URL: http://localhost:5173
      -> SusaLabs DLT-enabled editorial dashboard load ho jayega!
   4. Production build test karne ke liye:
      npm run build
      npm run lint

D. 3. MOBILE APP (REACT NATIVE / EXPO) RUN KAISE KARE:
   1. Naya terminal open kare aur news-app directory me jaye:
      cd news-app
   2. Dependencies install kare:
      npm install
   3. Expo dev server start kare:
      npx expo start
   4. Testing options:
      - Physical Phone: Expo Go app se terminal ka QR code scan kare.
      - Web Browser Preview: Terminal me 'w' dabaye.
      - Android Emulator: Terminal me 'a' dabaye.


7. IMPORTANT API ENDPOINTS REFERENCE
--------------------------------------------------------------------------------
Base URL: `http://localhost:5000/api`

- GET  /api/health                     -> Server & DB health check
- POST /api/auth/login                 -> Login with email & password / role
- POST /api/auth/register              -> Register new user account
- GET  /api/articles                   -> Get all published articles with category filter
- GET  /api/articles/:id               -> Get full article detail with audit dossier & DLT seal
- GET  /api/articles/hero              -> Get featured top hero dispatch
- GET  /api/videos                     -> Get live & replay video feeds
- POST /api/videos/:id/like            -> Like a video report
- POST /api/submissions               -> Submit citizen eyewitness news / whistleblower report
- GET  /api/submissions/my             -> View user's own submissions & review status
- GET  /api/dlt/ledger                 -> Full public DLT block ledger & validator stats
- GET  /api/dlt/verify/:id             -> Cryptographic SHA-256 anti-tamper verification
- POST /api/dlt/anchor/:id             -> Seal an article onto the immutable DLT ledger
- POST /api/support/ticket             -> Encrypted whistleblower tip & support intake
- POST /api/support/newsletter/subscribe -> Newsletter subscription
- PATCH /api/admin/submissions/:id/status -> Approve & seal with DLT / revise / reject
- GET  /api/sponsor-banner             -> Get active SusaLabs sponsored banner
